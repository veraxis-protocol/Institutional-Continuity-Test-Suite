No licence has been selected for the Institutional Continuity Test Suite.

This file exists so that the licensing status of this repository is explicit rather than
ambiguous. It is **not** a licence and it grants no rights.

## Why this is deliberate

ICTS is intended to be an independently implementable institutional conformance test suite.
The licence therefore has to answer questions that a default choice would silently foreclose:

- whether a third party may publish an independent implementation of `spec/`;
- whether a vendor may run the suite against its own product and publish the result;
- whether an assessor may run the suite commercially on behalf of an institution;
- whether the specification and the reference implementation carry the same terms;
- whether results and evidence bundles produced by the suite carry any downstream terms.

These are strategic questions about how the specification travels. They are not resolved by
picking a conventional licence, so no licence has been picked.

## What this does not block

Nothing in this repository depends on the licence being settled. The specification, the
reference implementation, the synthetic fixtures, and the governance process are all present
and executable now.
